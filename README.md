Сервис автоматического составления протоколов видео-встреч

Проект представляет собой систему для автоматического составления протоколов видео-встреч. Система принимает аудио- или видеофайл, выполняет его обработку, анализирует содержимое и формирует структурированный протокол встречи.

Архитектура системы

Система построена по модульному принципу и включает несколько ключевых компонентов:

Client → API (FastAPI) → RabbitMQ → Workers → Storage (PostgreSQL / S3 / FS)

## Основные компоненты:
- API-сервис
Обрабатывает входящие HTTP-запросы, управляет операциями и взаимодействует с очередями задач.
Очередь сообщений (RabbitMQ)
Обеспечивает асинхронную обработку задач и декуплинг компонентов системы.

- LLM Service (воркер анализа текста)
Слушает очередь llm_tasks (id_operation, transcription)
Выполняет анализ распознанного текста с помощью llm (развернутый в контейнере ollama) и формирует структурированный протокол.

- Хранилища данных
S3 - промежуточное хранение медиаданных
PostgreSQL — постоянное хранение данных
Файловая система — временное хранение аудио и промежуточных результатов

- STT Service (воркер распознавания речи)
Слушает очередь stt_tasks (id_operation, s3_key).
Выполняет распознавание речи с помощью локальной модели whisper, передает распознанный сырой текст в очередь llm_tasks.

- Ollama
Работает LLM, запросы на генерацию протокла идут сюда

-  Migrations
Alembic подключается к PostgreSQL и создает модель данных

## Также понадобится каталоги /tmp_data (к нему монтируется папка с результатом обработки) и /ollama_data (для старта контейнера)

## Структура проекта
```
project/
│
|--- app/
│     |--- api/ # REST API (роуты)
|     |      |--- routes.py
|     |
|     |--- main.py
│
|--- common/
|      |--- core/
|      |      |--- db.py
|      |      |--- db_service.py
|      |--- models/
|      |      |--- dto.py
|      |      |--- orm_models.py
|      |--- services/
|              |--- queue.py  # сервис очереди сообщений (enqueue, consume)
|              |--- s3_client # клиент для s3 хранилища
|
|--- llm_worker/              # воркер анализа текста
|       |--- llm/             # логика обработки текста
|       |--- worker.py        # обработчик для очереди
|
│--- stt_worker/             # воркер распознавания текста
|       |--- stt/            # логика распознавания речи
|       |--- worker.py       # обработчик для очереди
|
|--- alembic/             # Alembic миграции
|
|--- models/stt/
|            |--- model.bin  # stt-модель
|
|--- ollama_data/ # каталог для монтирования ollama контейнера
|
|--- tmp_data/ # каталог для монтирования временных файлов и итогового протокола внутри воркеров (Временно)
|
|--- docker-compose.yml
└
```
